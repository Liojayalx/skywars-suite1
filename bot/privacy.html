Privacy Policy

Last Updated: November 2026

1. Introduction

This Privacy Policy explains how LIO_ALX ("we", "our", or "the Bot") collects, uses, and safeguards information when added to a Discord server ("Guild"). We are committed to transparency and compliance with Discord's Developer Policy and applicable data protection regulations.

2. Information We Collect

LIO_ALX operates with strict data minimization principles. The only data processed or retained includes:

  • Discord User IDs & Guild IDs: Used as primary keys to associate leveling statistics (XP/Levels), warning infraction histories, and invite analytics.
  • Invite Metadata: Number of regular joins, leaves, and inviter user IDs to power the /invites tracking service.
  • Audit Log Records: Ephemeral action logs (e.g. channel deletion, role removal) analyzed in memory to detect rogue administrators or compromised bot accounts for Anti-Nuke defense.
  • Message Content (Ephemeral Only): Analyzed transiently in memory for auto-moderation rules (invite links, mass mentions, rate-limiting spam) and XP assignment. Message content is never stored permanently or logged to disk.

3. How We Use Information

Data collected is strictly used for the execution of the Bot's core features:

  • Delivering server security alerts and anti-nuke quarantines.
  • Maintaining user XP leaderboards and level milestones.
  • Logging disciplinary moderator actions (warnings, timeouts, kicks, bans).
  • Tracking server invitation credit for community members.

4. Data Storage and Security

All persistent statistics are maintained within a secure, isolated database hosted on dedicated infrastructure. We do not sell, rent, monetize, or disclose user data to any external third parties or advertising networks.

5. Data Retention and Deletion Requests

When LIO_ALX is removed from a Discord server, all server-specific settings and infraction records can be purged upon request. Any user may request total deletion of their associated user statistics (XP, warnings, invite records) by contacting our development team via our official GitHub repository or Discord community.

6. Contact Us

If you have any questions or requests regarding this Privacy Policy, please open an issue or reach out via our GitHub profile: github.com/Liojayalx.
